**冒泡排序**
```python
def sortArray(self, nums: List[int]) -> List[int]:
  for i in range(len(nums) - 1):
      for j in range(i, len(nums)):
          if nums[i] > nums[j]:
              nums[i], nums[j] = nums[j], nums[i]
  return nums
```
